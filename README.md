# 法人の裁判上の代表者 判定

当事者が法人であるとき、裁判上その法人を代表する者（又は当事者となる者）を判定するWebアプリと、その判定ルール・データです。

**アプリ：https://ordinarylawyer.github.io/houjin-daihyosha/**

法人の種類を選び、表示される要件（法人の状態、機関設計、訴訟の相手方など）に答えると、次のものを表示します。

- 裁判上の代表者（又は当事者となる者）
- 根拠条文
- 当事者の表示例（地位・法人名・資格・氏名を入れるとそのまま使える形にします）
- 注記と確認する資料

> 判定ルールとデータは、法令・裁判例・公開情報をもとに作成した参考情報です。実際の事件では、必ず登記事項証明書・条例・規約などの原資料で確認してください。

## 対象

| 区分 | 主な種類 |
|---|---|
| 会社 | 株式会社、特例有限会社、持分会社、外国会社 |
| 一般法人・公益法人等 | 一般社団・財団法人、NPO法人、学校法人、医療法人、社会福祉法人、宗教法人、管理組合法人、労働組合 |
| 協同組合等 | 農協・生協・事業協同組合・信用金庫など（協同組合型の各法人） |
| 公法人 | 国、地方公共団体、特別地方公共団体（一部事務組合・広域連合・財産区など 5,453 団体の一覧付き）、地方公営企業（設置条例 2,990 件の一覧付き）、独立行政法人等 |
| その他 | 法人でない社団、個別法による法人（143 種の一覧付き。相続財産法人・信託財産法人を含む） |

倒産手続（破産・民事再生・会社更生）、清算、役員との間の訴え、代表者の欠員などの場面も扱います。
種別 35・質問 255・ルール 510 です。質問に順に答えたときの全 875 パターンで、最優先のルールがちょうど 1 つ当たることを検査しています（[tests/検査結果.txt](tests/検査結果.txt)）。

## ファイルの構成

| 場所 | 中身 |
|---|---|
| `tools/rules_src.py` | **判定ルールの原本**（法人種別・質問・ルール） |
| `tools/corp_catalog_src.py`・`tools/corp_special.py` | その他の法人の一覧の原本と、役員との訴訟の特則 |
| `data/特別地方公共団体一覧.csv`・`data/特別地方公共団体_ウェブサイト.csv` | 特別地方公共団体の一覧（国税庁法人番号公表サイトのデータを基に作成）とウェブサイト |
| `data/地方公営企業_設置条例一覧.csv` | 地方公営企業の設置条例の一覧と、管理者の有無・代表者の推定 |
| `data/法人一覧_調査.csv` | その他の法人の一覧（`tools/build.py` が原本から作る、人が読む用） |
| `tools/build.py` | 検査し、`docs/07`・`seed/`・`tests/` と、アプリが読む `site/data/*.json` を作る |
| `site/` | Webアプリ（HTML・CSS・JavaScript だけ。サーバー不要） |
| `docs/` | 判定ルール一覧（07、自動生成）と、調べ方・根拠の整理（09・10・11・14） |
| `seed/` | 法人種別・質問・ルール・一覧の CSV（自動生成） |

## 誤りの報告・修正の提案

- 誤りに気づいたら、アプリの結果画面や一覧の「誤りを報告」から Issue を作ってください（GitHub のアカウントが必要です）。
- 直し方がわかる場合は Pull Request を歓迎します。手順は [CONTRIBUTING.md](CONTRIBUTING.md) にあります。

## 手元で動かす

[uv](https://docs.astral.sh/uv/) を使います（Python 3.11 以上。外部パッケージは使いません）。

```sh
uv run tools/build.py          # 検査して、生成物と site/data/*.json を作る
uv run tools/build.py --check  # 検査だけ
cd site && uv run python -m http.server 8000   # http://localhost:8000/ で確認
```

`main` ブランチに push すると、GitHub Actions が検査とビルドを行い、GitHub Pages に公開します。

## 出典

- 法令：e-Gov 法令検索（法令データ）
- 特別地方公共団体：国税庁 法人番号公表サイトの公開データ
- 条例・規約：条例Webアーカイブデータベース（同志社大学）https://jorei.slis.doshisha.ac.jp/
- 地方公営企業：総務省「地方公営企業年鑑」「経営比較分析表」（令和6年度決算）
- 裁判例：各ルールの根拠条文欄に記載

各ルール・各行の根拠は、それぞれの「根拠条文」「根拠」欄と `docs/` に書いてあります。

## 謝辞

このアプリの判定ルールと一覧は、次のデータベースに大きく助けられて作りました。心から感謝します。

- [条例Webアーカイブデータベース](https://jorei.slis.doshisha.ac.jp/)（同志社大学）：全国の地方公共団体の条例・規約を横断して検索でき、地方公営企業の設置条例（管理者の有無）や、一部事務組合・広域連合などの規約の確認に使わせていただきました。
- [Lawzilla（迷わない法令データベース）](https://lawzilla.jp/)：法令の条文と判例を、参照関係をたどりながら確かめることができ、判定ルールの根拠条文・裁判例の確認に使わせていただきました。
