## 2. 代表者の決まり方（法律）

| 種類 | 代表者 | 根拠 |
|---|---|---|
| 財産区 | 財産区がある市町村・特別区の長（表示は「同代表者○○市長」。「管理者」は加えない） | 地方自治法294条1項・147条 |
| 一部事務組合 | 管理者。執行機関の組織は規約で定める。規約で「組合長」と称していても法律上は管理者 | 地方自治法287条1項6号・292条 |
| 一部事務組合（理事会） | 285条の組合（複合的一部事務組合）は、規約で管理者に代えて理事会を置ける | 地方自治法287条の3第2項・3項 |
| 企業団 | 企業長（地方公営企業の経営を共同処理する一部事務組合の管理者の名称） | 地方公営企業法39条の2第1項・2項 |
| 広域連合 | 広域連合の長（規約で「広域連合長」とすることが多い）。規約で長に代えて理事会を置ける | 地方自治法291条の4第1項8号・291条の13・292条 |

アプリでは、代表者の資格を「管理者」とし、規約上の名称が組合長であることを注記します（表示は資格証明書・規約を見て決めてください）。

## 3. 条例Webアーカイブデータベース（https://jorei.slis.doshisha.ac.jp/）

- 同志社大学の条例Web作成プロジェクトのデータベース。都道府県・市区町村 1,788 団体の例規集を収集（「例規集一覧」）。
  一部事務組合・広域連合そのものの例規集は収録対象外。
- ただし、一部事務組合・広域連合・企業団の**規約は、構成団体の例規集に登載されている**ことが多く、ここで横断検索できる。
  平成27年度以降は廃止・改正された例規も残っている（改正前の規約も探せる）。
- 画面の検索は内部で Solr の検索 API（`/api/reiki/select`）を呼んでおり、例規名（title）・本文（content）・自治体・
  公布日・例規集の URL（reiki_url）が返る。例：`q=title:"企業団規約" AND collection:latest`。

### 規約から執行機関を拾った結果

「組合規約」「広域連合規約」「企業団規約」「機構規約」「事務組合規約」を例規名に含む例規 4,164 件（構成団体ごとに重複あり。規約名で約 1,450 種）を取得し、
「組合に○○を置く」の○○（管理者・組合長・理事会・理事長・企業長・広域連合長）で執行機関を判定しました。

| 判定 | 規約の数 |
|---|---|
| 管理者 | 865（うち出現数による推定 66） |
| 組合長 | 344（同 46） |
| 理事会・理事長 | 43 |
| 企業長 | 90 |
| 広域連合長 | 95 |

一覧（閉鎖を除く 1,540 団体）との照合結果：規約が見つかったもの 1,119、見つからなかったもの 421。
見つからなかったものは、確認状態を「未確認（規約をWeb等で確認）」にしています（企業団は法律で企業長と決まるので「法律で定まる」）。

主な理由：構成団体の例規集に規約が載っていない、一覧の名称と規約名の表記の違い（「ヶ」と「ケ」、読点、略称）、
規約名が「○○に関する規約」など別の名前になっている。

### アプリでの使い方

- Webアプリの特別地方公共団体の画面の「条例DBで規約」は、`https://jorei.slis.doshisha.ac.jp/search?simple=（名称） 規約` を開きます。
- 見つからない場合は「Webで検索する」（団体のサイトの例規集・規約のページを探す）。
- 確かめた代表者の資格は「記録する」で保存でき、確認状態が「利用者が確認（日付）」になります。

### 取り直すとき

1. 新しい法人番号の一覧 PDF を `pdftotext -layout` でテキストにする
2. ブラウザで条例Webアーカイブデータベースを開き、開発者ツール等で検索 API を呼んで規約を取得し、執行機関の記号を
   名称のハッシュ付きで `work/jorei_hash.txt` に書き出す（ハッシュ・正規化は `tools/special_import.py` の `h()`・`norm()` と同じ）
3. `uv run tools/special_import.py pw.txt pt.txt work/jorei_hash.txt` → `uv run tools/build.py`

## 4. 注意

- 財産区の「市区町村」は所在地（多くは市役所・町村役場）から推定したものです。財産区のある市町村と所在地の市町村が
  違う場合（合併後の旧町村の財産区など）は名称で確認してください。
- 規約は改正されます（執行機関を管理者から理事会に変える等）。訴状審査では、最新の規約と、管理者等の選任を証する書面で確認してください。
- 条例Webアーカイブデータベースの収集時期は団体ごとに違います（例規集一覧に例規集の更新日が出ます）。

## 5. ウェブサイト（2026-11-20）

財産区を除く 1,540 団体（一部事務組合・企業団・広域連合）について、ブラウザから DuckDuckGo（HTML 版、地域 jp-jp）で名称を検索し、
上位の結果を次の基準で振り分けた（Bing は途中から検索語を分解した結果しか返さなくなったため切り替えた）。
結果は `data/特別地方公共団体_ウェブサイト.csv`：**ウェブサイト 894 件・関連ページ 138 件・見つからない 508 件**。
自動判定の後、明らかな誤り（スパムサイト・求人・葬儀社や病院の検索サイト等）は目視で除いた。

| 区分 | 基準 |
|---|---|
| S（ウェブサイト） | 結果のタイトルに団体の名称がそのまま含まれ、そのページがサイトのトップ（パスの階層が 1 以下）であるもの。トップが出なくても、同じホストのページが 2 件以上タイトルに名称を含むときはそのホストのトップ |
| P（関連ページ） | 団体のサイトは見つからないが、構成市町村・都道府県のサイト（`*.lg.jp`、`city.`・`town.`・`vill.`・`pref.` を含むホスト）に、タイトルに名称を含むページがあるもの |
| （なし） | 上記に当たらない。法人情報のまとめサイト・地図・求人・例規集・Wikipedia 等は除外 |

- 名称が部分的にしか一致しない（略称や「消防本部」等の別名でサイトを運営している）団体は拾えていない。画面の「URLを記録」で補う
- 財産区は通常ウェブサイトを持たないので対象外（必要なら画面で記録する）
- 自動判定なので、画面では「検索で確認」と表示している。誤りに気づいたら「URLを記録」で上書きする（`U:` は反映用の投入式で上書きされない）
