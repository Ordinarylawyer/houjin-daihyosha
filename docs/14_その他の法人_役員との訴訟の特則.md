# その他の法人の「役員との訴訟」の特則（準用関係の調べ直し）

作成 2026-11-20（実装前の調査。seed/05 とアプリはまだ変えていない）

## 1 調べた理由

その他の法人（ET）で一覧から法人を選び「法人と代表者（役員）との間の訴訟ですか」に「はい」と答えると、一覧の「特則」欄を表示する（ET-L2）。特則欄が空の法人が多く、例えば農業協同組合で元理事との訴訟を選ぶと「定めなし」になっていた。種別「協同組合等」（NK・SS・CK）では会社法386条の準用で正しく「監事」になるので、食い違っていた。

## 2 調べ方

(1) 一覧の根拠法 93本の現行条文を e-Gov 法令API v2（https://laws.e-gov.go.jp/api/2/ 、2026-11-20取得）で全文取得し、附則を除く本則から次の書き方を機械的に拾い、該当箇所を読んで法人ごとに当てはめた（`work/othercorp/proposal.py`）。
   - 会社法386条1項1号・2項1号2号の準用（監事が「理事（理事であった者を含む。）」との訴えで法人を代表）
   - 会社法353条・364条の準用（総会・理事会が定める者）
   - 「理事と契約するときは監事が代表する。理事との訴訟についても同様」
   - 「（代表権のある役員）との利益が相反する事項については代表権を有しない。この場合には監事が代表する／特別代理人を選任する」
   - 「理事との訴訟については総会の定める者が代表する」
   - 持分会社の会社法601条の準用（士業法人）
   - 独立行政法人通則法24条の準用（法テラス・国立健康危機管理研究機構・福島国際研究教育機構）
(2) e-Gov API で全文を取得できなかった地方公務員等共済組合法・地方公務員災害補償法は、Lawzilla で確認した（地共法の 3件は現行データのまま）。

## 3 型（どの訴えに効くか）

| 型 | 内容 | 元理事との訴訟 |
|---|---|---|
| A | 会社法386条準用 → 監事 | 監事（386条1項1号は「取締役であった者を含む」） |
| A' | 同上。監査権限限定組合は353条・364条（総会・理事会が定める者。なければ代表理事）。監事は登記されず、監査の範囲の限定も定款でしか分からないので、どちらの結論でも定款の確認が要る | 同左 |
| E | 353条・364条準用だけ（監事は会計監査のみ） | 総会・理事会が定める者。なければ代表理事 |
| B / B2 | 理事との契約・訴訟（争訟）は監事 | 明文なし（「理事」との訴訟。解釈。元理事を含むかは要検討） |
| B3 | 理事との契約だけ監事（訴訟の定めなし） | 通常の代表者 |
| C | 法人と現任の代表権者の利益相反事項 → 監事 | 対象外（現任の代表者に利益相反がなければ通常の代表者） |
| C' | 同上 → 特別代理人（裁判所・知事・総会決議が選任） | 対象外 |
| D | 理事との訴訟は総会の定める者 | 明文なし |
| F | 会社法601条準用：法人と社員の訴えで代表者がいないとき、他の社員の過半数で代表者を定める | 社員であった者との訴えは対象外 |
| N | 根拠法に特則なし | 通常の代表者（利益相反で代表者がいなければ民事訴訟法35条の特別代理人） |
