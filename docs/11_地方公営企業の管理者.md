# 11 地方公営企業の管理者が代表者・当事者になる場合（調査メモ）

2026-11-20 調査（外出中のためリサーチのみ。アプリへの組込みは未着手）。
条文は Lawzilla（e-Gov 法令データ）、裁判例は Lawzilla の判例、条例は条例Webアーカイブデータベース（同志社大学）の検索 API で確認した。

## 1 結論の要約

(1) 管理者を置く地方公営企業では、その業務の執行に関する訴訟（民事訴訟・抗告訴訟）は、**地方公共団体が当事者、管理者が代表者**になる（地方公営企業法8条1項）。
(2) 管理者が地方公共団体を代表しないのは、予算の調製、議案の提出、決算を監査委員の審査・議会の認定に付すること、過料を科すること（同条1項1号〜4号）と、法令に特別の定めがある場合（同項ただし書）。
(3) 管理者を置かない企業（7条ただし書・条例）と、財務規定等だけを適用する企業（病院事業の当然財務適用、任意の一部適用）は、**長**が代表する（8条2項、34条の2）。
(4) 管理者**自身**が当事者（被告）になるのは、主に**住民訴訟の1号（差止め）・3号（怠る事実の違法確認）・4号（損害賠償等の請求を求める請求）**で、公営企業の業務に係る行為・怠る事実が対象のとき。裁判例も「被告○○市水道事業管理者」等としている（後記4）。
(5) 管理者の有無は、①法律上の必置／任意、②条例（「○○事業の設置等に関する条例」で「管理者を置かない」等）、③総務省の「経営比較分析表」の「管理者の情報」（非設置／職歴）で調べられる。名称（水道事業管理者・上下水道事業管理者・企業管理者・水道局長など）は、設置等条例・組織条例で決まる。

## 2 条文の整理

| 条文 | 内容 |
|---|---|
| 地方公営企業法2条1項 | 当然適用（全部適用）の事業：水道（簡易水道を除く）・工業用水道・軌道・自動車運送・鉄道・電気・ガス |
| 同2条2項 | 病院事業は財務規定等だけが当然適用（管理者の規定は当然には適用されない） |
| 同2条3項 | その他の事業（下水道・病院等）は、条例（一部事務組合・広域連合は規約）で全部又は一部を適用できる |
| 同7条 | 事業ごとに管理者を置く。ただし条例で、政令で定める企業には管理者を置かず、又は二以上の事業を通じて管理者一人を置ける（水道＋工業用水道、交通事業は一人が常例） |
| 同施行令8条の2 | 管理者を**置かなければならない**規模（これ以外は置かないことができる）：水道＝職員200人以上かつ給水5万戸以上、工業用水道＝職員100人以上かつ給水能力50万m³/日以上、交通＝職員200人以上かつ車両150両以上、電気＝職員100人以上かつ5万kW以上、ガス＝職員100人以上かつ供給2万戸以上 |
| 同7条の2 | 管理者は長が任命、任期4年、常勤 |
| **同8条1項** | 管理者は、1号〜4号の事項を除き、地方公営企業の業務を執行し、**当該業務の執行に関し当該地方公共団体を代表する**。法令に特別の定めがある場合を除く |
| 同8条2項 | 管理者を置かない地方公共団体では、管理者の権限は**長**が行う |
| 同9条 | 管理者の担任事務（職員の任免・懲戒、資産の取得・管理・処分、契約、料金等の徴収、労働協約 等） |
| 同34条 | 職員の賠償責任（地方自治法243条の2の9）を準用。管理者を置く企業では、賠償命令をするのは**管理者**（長を管理者と読み替え） |
| 同34条の2 | 財務規定等だけが適用される企業では、管理者の権限は**長**が行う |
| 同39条の2 | 企業団（地方公営企業を共同処理する一部事務組合）の管理者の名称は**企業長**。広域連合企業団は条例・規約で管理者を置かないこともできる |
| 同40条2項 | 業務に関する訴えの提起・和解等は、条例で定めるものを除き議会の議決（地方自治法96条1項12号）を要しない |
| 地方公務員法3条3項1号の2 | 地方公営企業の管理者・企業団の企業長は特別職 |
| 地方自治法242条の2第1項 | 住民訴訟。1号・3号は「当該執行機関又は職員」、4号は「当該普通地方公共団体の執行機関又は職員」に対する請求。4号ただし書：相手方が243条の2の9第3項の賠償命令の対象者なら、賠償命令をすることを求める請求 |

## 3 当事者・代表者の表示パターン

| 場面 | 当事者 | 代表者・表示 | 根拠・参考 |

| (2) 管理者がした処分の抗告訴訟（下水道使用料の納入通知、職員の懲戒処分、34条の賠償命令など） | 地方公共団体（行訴法11条1項） | 同代表者兼処分行政庁　○○市水道事業管理者　氏名 | 8条1項、行訴法11条。東京地判平27.10.27（下水道使用料納入通知処分取消。被告東京都を東京都下水道局長が代表すると認定） |

| (5) 管理者を置かない企業、財務規定等だけの企業（病院の当然財務適用など） | 地方公共団体 | 長 | 8条2項、34条の2 |
| (6) 住民訴訟1号（差止め）・3号（怠る事実の違法確認）・4号（請求を求める請求） | **管理者自身**（執行機関又は職員） | 被告　○○市水道事業管理者（4号は「被告は、Aに対し、…を請求せよ」型） | 地方自治法242条の2第1項。裁判例は後記4 |
| (7) 住民訴訟4号で相手方が賠償命令の対象職員 | 管理者自身 | 「管理者は、Aに対し賠償の命令をせよ」型 | 242条の2第1項4号ただし書、地方公営企業法34条（長→管理者の読替え） |
| (8) 住民訴訟2号（処分の取消し・無効確認） | 地方公共団体 | 処分をした管理者が代表（(2)と同じ） | 242条の2第1項2号、行訴法43条・11条 |
| (9) 4号判決確定後、地方公共団体が相手方に請求する訴訟 | 地方公共団体 | 原則は事業の管理者。相手方が長なら代表監査委員（242条の3第5項）。**相手方が管理者自身の場合の定めは見当たらない**（要検討：特別代理人等） | 242条の3 |
| (10) 企業団・広域連合企業団 | 企業団 | 企業長（特別地方公共団体の画面で対応済み） | 39条の2 |

表示のメモ
(1) 資格は条例上の名称による（水道事業管理者、上下水道事業管理者、病院事業管理者、企業管理者、公営企業管理者など）。二以上の事業を通じて一人を置く場合は「企業管理者」「上下水道事業管理者」等の名称が多い（例：習志野市は「本市が経営する各事業を通じて企業管理者1人を置く」）。
(2) 東京都は、東京都公営企業組織条例で水道局長・下水道局長を管理者としている（上記東京地判の前提事実）。アプリの既存ルール CH-B1 の注記（「東京都のように事業の名称の定めがない場合は『公営企業管理者』」）は、この判決と合わない可能性がある。→ 2026-11-20 方針決定：**既存ルールを優先**し、CH-B1 の注記は変えない（東京都は特殊な取扱いの可能性がある）。

## 5 管理者の有無・名称の調べ方

### 5.1 条例Webアーカイブデータベース（例規集横断検索）

検索 API（`/api/reiki/select`、最新版は `collection:latest`）で件数を確認した。

| 条件（例規名に「設置等に関する条例」） | 件数 |
|---|---|
| すべて | 5,255（公の施設の設置条例を含む） |
| 本文に「地方公営企業法」 | 2,859 |
| 本文に「管理者を置かない」 | 1,117 |
| 本文に「規定の全部を」（任意の全部適用） | 797 |
| 本文に「管理者一人を置く」 | 9（実際は「企業管理者1人を置く」など表記揺れが多い） |

例：
(1) 「管理者を置かない」：奥州市病院事業、綾町・美浜町・太地町・稲敷市・伊江村の各水道事業の設置等に関する条例 など。
(2) 一人を置く：習志野市公営企業の設置等に関する条例4条「法第7条ただし書の規定により、本市が経営する各事業を通じて企業管理者1人を置く」、5条「企業局を置く」、2条で下水道事業に全部適用。

注意点
(1) 管理者を**置く**ことは法律（7条本文）が定めるので、条例に書かれていないことが多い。条例から確実に読めるのは「置かない」「一人を置く」「全部を適用する」。
(2) したがって「当然適用の事業がある」かつ「置かない旨の条例がない」→ 管理者あり、と推定する組み立てになる。事業があるかどうかは別の資料（経営比較分析表・決算状況調査）で補う。
(3) 名称は設置等条例のほか、組織条例（「○○市公営企業組織条例」「上下水道局設置条例」等）や企業管理規程に出てくる。

### 5.2 総務省「経営比較分析表」の「管理者の情報」

(1) 法適用企業の経営比較分析表には「管理者の情報」欄があり、管理者を設置している場合はその職歴（自治体職員、民間人材など）、設置していない場合は「非設置」と記載される（山口県・埼玉県・岡山県の掲載資料で確認）。
(2) 水道・下水道・工業用水道・交通・電気・病院・駐車場・観光施設事業などについて、**団体×事業ごと**に作成・公表されている。
(3) 有無の判定にはこれが最も直接的。総務省・都道府県のページで Excel／PDF が公開されている。
(4) この作業環境からは総務省・デジタル庁のサイトへ一括ダウンロードできなかった（通信先の制限）。取得は、次回ブラウザ（内蔵ブラウザ等）が使えるときに行う。

### 5.3 その他
(1) 規模要件（施行令8条の2）を満たす水道・交通等は管理者が必置。大都市・都道府県企業局はほぼ該当。
(2) 病院事業は、全部適用の条例がある場合だけ管理者を置ける（「病院事業管理者」）。
(3) 下水道事業は任意適用。全部適用なら管理者を置ける（上下水道で一人の例が多い）。

   - 年鑑が「設置」で推定が長のときに管理者へ変えたのは、次の条件を全部満たす場合だけ（11件）。①財務適用の規定がない。②全部適用の規定があるか、当然全部適用の事業（水道・水道用水供給・工業用水道・交通・電気・ガス）である。③都道府県・市・組合であるか、管理者の名称がある。④「置かない」の規定がない。

     - 「置かないことができる」（任意）、期限付きの規定（「任命するまでの間」など）、廃止された「置かない条例」の題名にしか当たらないもの（根室・美唄・仙北・赤穂・香美・奥州・西脇・岩国・川越など）→ 管理者（9件）。
     - 「置かないものとする」と明記したもの → 長のまま（48件、根拠に年鑑との食い違いを書いた）。
   - 年鑑が「非設置」で推定が管理者 → 長（13件）。ただし条例本文に管理者の名称がある場合は除く。
   - 同じ条例の事業で設置・非設置が分かれるもの → 「事業により異なる」（大間町・福島市・ひたちなか市・明石市。米子市は従来から）。
   - 年鑑で決まらない行は適用条例の本文を読んだ（`work/koei/v2/tekiyo_ctx.json`）。「財務規定等を（令和…から）適用する」→ 長（確度 高、94件）。「置かないものとする」→ 長。全部適用で置かない規定なし → 管理者（確度 中）。
